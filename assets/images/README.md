# 📸 Polaroid Photos Folder

Place your friend's photos here to display them on the **Polaroid Memory Lane** section!

### How to use:
1. Copy your photos into this folder:
   - `assets/images/photo1.jpg`
   - `assets/images/photo2.jpg`
   - `assets/images/photo3.jpg`
   - `assets/images/photo4.jpg`
   - `assets/images/photo5.jpg`
   - `assets/images/photo6.jpg`
   *(PNG, JPG, WebP are all supported!)*

2. Open `assets/config.js` and set the `image` field for each memory:
   ```javascript
   image: 'assets/images/photo1.jpg',
   ```

3. Save the file and refresh your browser! If any photo is left empty (`image: ""`), the website will automatically display a cute romantic illustrated icon instead.
